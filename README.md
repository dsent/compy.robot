# Compy robot

Driving an ElecFreaks TPBot Edu robot from a Compy.

| Path | What it is |
| --- | --- |
| `drive/` | Drives a TPBot with the keys, each move into `r.lua` |
| `slalom/` | Sends `r.lua` to the micro:bit a line at a time, at its prompt |

The board runs the Lua firmware that Compy IDE bundles; `robot_move` is
built into it.
